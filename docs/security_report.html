Patches Applied

VULN-02: Join Payload Whitelist

PATCHEDCRITICAL

Root cause: applyMessage('join') spread the entire payload into the player object, allowing injection of isAdmin, spark, or any field.

Fix: Whitelist of allowed join fields: ['name', 'position', 'zone', 'avatar', 'platform']. Also blocks __proto__ and constructor.
File: src/js/state.js | Lines: 197-216

VULN-03: Position Bounds Clamping

PATCHEDHIGH

Root cause: Move messages accepted arbitrary coordinates including ±Infinity, NaN, and extreme values that could crash rendering or position players off-map.

Fix: clampPosition() limits all coordinates to ±10,000 and converts NaN/undefined/strings to 0.
File: src/js/state.js | Lines: 22-29, 238

VULN-04: Timestamp Freshness Check

PATCHEDCRITICAL

Root cause: No timestamp validation beyond format. An attacker could send messages with far-future timestamps to always win conflict resolution (last-writer-wins uses timestamp comparison).

Fix: validateMessage() rejects timestamps more than 5 minutes in the future.
File: src/js/protocol.js | Lines: 197-200

VULN-06: UBI Drain Protection

PATCHEDCRITICAL

Root cause: distributeUBI() could be called repeatedly within the same time period, draining the treasury. A malicious client or buggy game tick could invoke it in a loop.

Fix: Epoch-based deduplication — only one UBI distribution allowed per hour-epoch. Second call returns { distributed: 0 }.
File: src/js/economy.js | Lines: 459-474

VULN-07: Chat XSS Sanitization

PATCHEDHIGH

Root cause: Chat messages stored raw user text. If rendered in HTML, <script> tags, <img onerror> payloads, or CSS injection could execute.

Fix: sanitizeText() strips HTML angle brackets, control characters (keeping \n\r\t), and truncates to 500 characters.
File: src/js/state.js | Lines: 9-15, 268

VULN-08: Zone Default-Deny

PATCHEDHIGH

Root cause: isActionAllowed() returned true for any action not in the ACTION_RULE_MAP, meaning novel/unknown action types bypassed all zone rules.

Fix: Two-tier approach: ALWAYS_ALLOWED_ACTIONS (say, move, join, etc.) bypass zone rules. ACTION_RULE_MAP (build, harvest, trade, etc.) check zone rules. Everything else is denied by default.
File: src/js/zones.js | Lines: 148-159, 185-194

VULN-10: Payload Size Limit

PATCHEDHIGH

Root cause: No size limit on protocol message payloads. A single 100MB chat message could crash peers via memory exhaustion or P2P bandwidth saturation.

Fix: validateMessage() rejects payloads exceeding 10KB when serialized. Also catches payloads that can't be serialized (circular references).
File: src/js/protocol.js | Lines: 260-269

VULN-12: Balance Floor Guards

PATCHEDMEDIUM

Root cause: Economy operations could result in negative balances or NaN values through edge cases in transfer/spend operations.

Fix: Balance floor of 0 enforced after every operation. NaN amounts rejected at API boundaries. (Applied in earlier bugfix commit.)
File: src/js/economy.js | BALANCE_FLOOR constant + guards
